1. System Architecture

Architectural style: Local-first three-tier architecture.

  • Presentation tier: React + Vite frontend (src/main.tsx, src/App.tsx).
  • Application/API tier: Node.js + Express backend (server.js).
  • Data tier: Local MySQL database (toda) and local file storage for driver photos and temporary CSV files.
  • External dependency: Google Forms complaint form used by commuters after QR scan.
